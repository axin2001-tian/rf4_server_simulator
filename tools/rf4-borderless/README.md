# rf4-borderless

修正《俄罗斯钓鱼 4》「无边框窗口」残留标题栏的小工具（Windows）。

## 背景

游戏设置里的「无边框窗口」实测只是把窗口尺寸改成屏幕大小，标题栏并没有去掉：

- 窗口外框因此比显示器大一圈（例如 1938x1127），底部超出屏幕；
- Alt+Tab 切出再切回、或者重启游戏之后，Unity 还会把标题栏重新写回来。

本工具常驻监视 `rf4_x64.exe` 的主窗口：只要发现窗口带标题栏、外框又已经铺满整块显示器，
就去掉标题栏并把窗口贴到显示器左上角；玩家主动切回小窗口时再把边框还原。

## 行为

- 窗口出现后等待 25 秒才动手：Unity 初始化 D3D 交换链期间修改窗口样式会导致游戏退出。
- 每 300ms 检查一次；同一次修正后 2 秒内不会重复修改，避免和游戏互相抢样式。
- 已经是无边框、最小化、不可见的窗口不处理。
- 真正的小窗口（例如 1280x720）不处理，不会被强行改成全屏。

判定逻辑在 `src/borderless.h` / `src/borderless.cpp`，不依赖 Windows API，可直接单测。

## 构建

需要 MinGW-w64 的 `g++` 在 `PATH` 中：

```powershell
.\build.ps1
```

输出 `bin\rf4-borderless.exe`。

## 运行

```powershell
.\bin\rf4-borderless.exe
# 可选参数
.\bin\rf4-borderless.exe --interval 300 --grace 25000
```

工具会自动查找 `rf4_x64.exe` 并跟随其主窗口，可以先启动工具再启动游戏，也可以游戏运行中再启动。
关闭控制台窗口或按 Ctrl+C 退出。

## 测试

```powershell
.\test.ps1
```

测试只覆盖纯逻辑判定（带标题栏全屏、启动宽限期、小窗口、已无边框、最小化/隐藏、容差边界、样式计算），
不依赖游戏进程。

## 说明

该判定逻辑与实机使用的传送面板内置实现一致，已在 1920x1080 / 125% 缩放、Windows 10 下验证：
修正后窗口为无标题栏全屏，Alt+Tab 切回仍能自动恢复。
